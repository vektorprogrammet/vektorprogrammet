## Authentication & Authorization

### Security Configuration

**File:** `app/config/security.yml`

#### Role Hierarchy

- `ROLE_ADMIN` (includes: USER, TEAM_MEMBER, TEAM_LEADER)
- `ROLE_TEAM_LEADER` (includes: USER, TEAM_MEMBER)
- `ROLE_TEAM_MEMBER` (includes: USER)
- `ROLE_USER` (base role)

#### User Providers

- Chain provider supporting:
  - Username authentication (`db_username`)
  - Email authentication (`db_email`)
  - Company email authentication (`db_company_email`)

#### Firewalls

1. `dev` - Assets/profiler (no auth)
2. `admin_area` - HTTP Basic Auth for `/admin`
3. `secured_area` - Main application firewall with:
   - Form login
   - Remember me (1 year)
   - Anonymous access
   - HTTP Basic Auth support

#### Access Control Rules

Complex access control based on:

- Path patterns (`^/kontrollpanel/admin`, etc.)
- Roles (ROLE_ADMIN, ROLE_TEAM_LEADER, ROLE_TEAM_MEMBER, ROLE_USER)
- Methods (GET, POST)

**Laravel Migration:**

- Convert to Laravel Policies for model-based authorization
- Use Gates for route/action-based authorization
- Implement middleware for role checks
- Convert access control rules to route middleware groups
